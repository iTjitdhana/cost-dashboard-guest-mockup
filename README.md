# หน้าตัวอย่าง Dashboard ต้นทุน — มุมมองผู้เยี่ยมชม

หน้านี้ใช้ให้ทีมออกแบบเห็นหน้าตา ฟีเจอร์ และเงื่อนไขการแสดงของมุมมองผู้เยี่ยมชม ตัวเลขเป็นตัวอย่าง ไม่ได้ต่อฐานข้อมูล

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย

แถบสีเหลืองด้านบนเขียนว่า "หน้าตัวอย่าง" แถวนั้นไม่มีในระบบจริง ใช้บอกว่าแต่ละแถวโชว์เงื่อนไขอะไร

## ระบบจริงทำงานอย่างไร

หน้าผู้เยี่ยมชมอยู่ที่เส้นทาง `/guest/cost-dashboard` ไม่ต้องล็อกอิน

เบราว์เซอร์เรียก

`GET /api/public/cost-dashboard/daily`

ได้รายการของวันนี้รายการเดียวกับหน้ารายวันของหน้าหลัก ทั้งสองหน้าใช้ฟังก์ชัน `getDailyOverview` ชุดเดียวกัน

มีช่องทางแจ้งเตือน `GET /api/public/cost-dashboard/stream` เมื่อมีการบันทึกจำนวนที่ผลิตได้ หน้าจะโหลดรายการใหม่ ช่องทางนี้ไม่ส่งเนื้อหางาน

หน้าหลักอยู่ที่ `/cost-dashboard` ต้องล็อกอินและมีสิทธิ์ `admin.cost_dashboard.view` หน้าหลักมีเพิ่มจากผู้เยี่ยมชมคือ เลือกวัน ค้นหาประวัติ และแท็บความครบของข้อมูล

## ข้อมูลดึงจากตารางไหน

รายการเริ่มจากแผนงานของวันนั้นใน `work_plans` กรอง `production_date` เป็นวันนั้น เรียง `start_time` แล้วตาม `id` ลำดับนี้คือเลขลำดับบนหน้าจอ

| สิ่งที่หน้าจอโชว์ | มาจาก |
|---|---|
| รหัสงาน ชื่องาน | `work_plans.job_code`, `work_plans.job_name` |
| วันผลิต | `work_plans.production_date` |
| ลำดับ | ลำดับหลังเรียง `start_time`, `id` |
| ป้ายยกเลิก | `work_plans.status_id = 9` ชื่อสถานะจาก `production_statuses.name` |
| ผู้ปฏิบัติงาน | `work_plan_operators` เชื่อม `users.name` |
| RM LM ต้นทุนรวม จำนวนผลิต หน่วย | `production_costs.material_cost`, `labor_cost`, `total_cost`, `output_qty`, `output_unit` |
| จำนวนคนที่ใช้คิดค่าแรงเมื่อบันทึกแล้ว | `production_costs.operators_count` |
| ค่าแรงต่อวันที่เคยบันทึก | `production_costs.material_details` |
| น้ำหนักวัตถุดิบตั้งต้นของ Yield | `production_costs.input_material_qty` |
| ผลผลิตและเศษเมื่อยังไม่อ่านจากต้นทุนที่บันทึก | `batch_production_results.good_qty`, `good_secondary_qty`, `defect_qty` |
| มีการตวงสูตร | `batch_material_usage.actual_qty > 0` ของ `production_batches` |
| RM ระหว่างผลิตถ้ายังไม่มีต้นทุนที่บันทึก | ผลรวม `batch_material_usage.actual_qty × unit_price` |
| เวลาผลิต | `process_executions.start_time`, `end_time` ของงานหรือของแบตช์ ถ้าไม่มีค่อยใช้เวลาจาก log |
| ขั้นตอนที่ยังไม่จบ | ขั้นตอนล่าสุดที่กดเริ่มแล้วยังไม่กดจบ |
| เวลามาตรฐาน | รวม `process_templates.estimated_duration_minutes` ตามเวอร์ชันใน `product_active_versions` ถ้าไม่มีใช้ `process_patterns.manual_total_minutes` |
| หมวดหมู่สินค้าบนแถบสี | `products` → `product_tag_groups` → `tag_groups.name` เช่น BNL, B2B, BUย่อย, เบิกของ |
| กลุ่มงานในหน้ารายละเอียด | คำนวณจากรหัสงาน ไม่ได้เก็บเป็นคอลัมน์ |

งานประเภท `work_plans.job_type = default` จะไม่โชว์ ถ้าวันเดียวกันมีแผนงานรหัสเดียวกันของหน่วยธุรกิจเดียวกันอยู่แล้ว

## ฟิลด์ที่ส่งมาที่หน้าจอ

ชื่อฟิลด์ด้านซ้ายคือชื่อใน JSON ของ API ด้านขวาคือความหมายบนหน้า

| ฟิลด์ | ความหมาย |
|---|---|
| `jobCode` `jobName` | รหัสและชื่อที่โชว์ในแถว |
| `jobSequence` | เลขลำดับ |
| `operators` | ชื่อผู้ปฏิบัติงาน |
| `materialCost` | RM บาท |
| `laborCost` | LM บาท |
| `totalCost` | ต้นทุนรวม บาท |
| `costSource` | `saved` ต้นทุนจริง, `estimated` ประมาณการ, `none` ยังไม่แสดงเงิน |
| `standardMinutes` `standardLaborCost` `standardTotalCost` | เวลามาตรฐาน LM มาตรฐาน และ RM+LM มาตรฐาน |
| `hasStandardTime` | มีเวลามาตรฐานในระบบ |
| `outputQty` `outputUnit` | จำนวนที่ผลิตได้และหน่วย |
| `yieldPercent` | เปอร์เซ็นต์ Yield โชว์เมื่อ RM มากกว่า 0 |
| `timeUsedMinutes` `timeUsedSeconds` `timeSource` | เวลาที่โชว์ `actual` คือเวลาผลิต |
| `timerLiveStartedAt` | มีค่าเมื่อกำลังจับเวลา หน้าจอใช้ไล่เวลาต่อทุกวินาที |
| `timerStatus` | `ok` ปกติ, `warn` ต้องตรวจสอบเวลา, `no_data` ไม่มีข้อมูลเวลา |
| `dataCompleteness` | ครบสามส่วนหรือไม่: ราคาวัตถุดิบ, กดเวลาครบ, บันทึกผลผลิต |
| `costReliabilityPercent` | ความถูกต้องต้นทุนตามกลุ่มงาน |
| `jobCategory` | กลุ่มงาน production, repack, vegetable, requisition, formula, other |
| `productCategories` | ป้ายหมวดหมู่สินค้า |
| `isCancelled` | ยกเลิกการผลิต |
| `isFinished` | ผลิตเสร็จแล้ว |
| `currentStepName` | ชื่อขั้นตอนที่ยังไม่จบ |
| `productionStatusName` | ชื่อสถานะแผนงาน ใช้บนป้ายยกเลิก |

## วิธีคิดเงิน

ค่าแรงเริ่มต้น 450 บาทต่อคนต่อวัน นาทีมาตรฐานต่อวัน 495 นาที (8 ชั่วโมง 15 นาที) ตั้งที่ตัวแปร `LABOR_DEFAULT_DAILY_WAGE` และ `LABOR_STANDARD_WORK_MINUTES`

LM = จำนวนคน × ค่าแรงต่อวัน × (นาทีที่ผลิต ÷ 495)

จำนวนคนใช้ `operators_count` ถ้ามากกว่า 0 ไม่งั้นนับจำนวนชื่อ ถ้าไม่มีชื่อเลยใช้ 1 คน

ต้นทุนจริง (`saved`) ใช้เมื่อบันทึกจำนวนผลิตแล้ว และ `production_costs.total_cost` มากกว่า 0

ระหว่างผลิต (`estimated`) ต้นทุนรวม = RM + LM จากเวลาผลิตจริง ยังไม่มีเวลาผลิตจะยังไม่แสดงต้นทุนรวม

งานที่ยกเลิก (`status_id` 9) และยังไม่บันทึกผลผลิต จะไม่แสดง RM LM และต้นทุนรวม

Yield = (น้ำหนักขายได้ + เศษ) ÷ น้ำหนักวัตถุดิบตั้งต้น × 100 น้ำหนักขายได้ใช้ `good_secondary_qty` ถ้ามากกว่า 0

## กลุ่มงานจากรหัส

| เงื่อนไขรหัส | กลุ่ม |
|---|---|
| ลงท้ายด้วย R หรือรหัส 135014, 240003 | repack |
| ขึ้นต้น 153005 | vegetable งานทำผัก |
| ตัวแรก A B หรือ C | requisition งานเบิกของ |
| ตัวแรก D | formula งานตวงสูตร |
| เป็นตัวเลขล้วน ยาวมากกว่า 3 ตัว และไม่ใช่ 1000 หรือ 135010 | production |
| ที่เหลือ รวมรหัส 1000 และ 135010 | other |

ความถูกต้องต้นทุนนับเฉพาะส่วนที่กลุ่มนั้นต้องมี

| กลุ่ม | ต้องมีราคา | ต้องมีเวลา | ต้องมีผลผลิต |
|---|---|---|---|
| production, repack | ใช่ | ใช่ | ใช่ |
| vegetable, requisition, formula, other | ไม่ | ใช่ | ไม่ |

ป้าย "ผลิตเสร็จแล้ว" ขึ้นเมื่อมีจำนวนผลิต หรือกลุ่มนั้นไม่ต้องมีผลผลิตและจับเวลาครบทุกขั้นตอนแล้ว

แถวสีเทาคือหมวดหมู่สินค้าไม่มี BNL, B2B, BU หรือ BUย่อย ระบบยังไม่คำนวณต้นทุนของแถบนี้เป็นงานติดตามต้นทุน

## ฟีเจอร์บนมุมมองผู้เยี่ยมชม

- การ์ดสี่ใบ: ต้นทุนรวมวันนี้, Yield เฉลี่ย, ข้อมูลครบ, ต้องตรวจสอบ
- ตัวกรอง: ทั้งหมด, ต้องตรวจสอบเวลา, ข้อมูลไม่ครบ, Yield ต่ำ
- ตารางเรียงตามหัวคอลัมน์ได้ บนจอเล็กเป็นการ์ด
- คลิกแถวเปิดรายละเอียด เทียบมาตรฐานกับของจริง และแสดงความครบของข้อมูล
- งานที่กำลังจับเวลา เวลาและ LM ขยับทุกวินาทีบนหน้าจอ
- ปุ่มโหลดใหม่
- ไม่มีปุ่มเปิดหน้าจับเวลา ปุ่มนั้นมีเฉพาะหน้าหลัก

การ์ดต้นทุนรวมไม่เอางานที่ยกเลิกมารวม

## เงื่อนไขการแสดง

| สิ่งที่เห็น | เงื่อนไข |
|---|---|
| แถวพื้นแดง ชื่อขีดฆ่า ป้ายยกเลิก | `isCancelled` จาก `status_id` 9 |
| แถวพื้นเทา ชื่อสีจาง | หมวดหมู่ไม่มี BNL, B2B, BU, BUย่อย |
| ป้ายผลิตเสร็จแล้วสีเขียว | `isFinished` และยังไม่ยกเลิก |
| ป้ายกำลังผลิต และเวลาแบบ ชั่วโมง:นาที:วินาที | กำลังจับเวลา ยังไม่ยกเลิก เวลาเป็นเวลาผลิต และสถานะเวลาไม่ใช่ปกติ |
| คำว่า เวลาผลิต | `timeSource = actual` |
| คำว่า เวลามาตรฐาน สีอำพัน | `timeSource = standard` ในข้อมูลจริงคอลัมน์เวลาของหน้ารายวันโชว์เฉพาะเวลาผลิต เวลามาตรฐานไปอยู่ที่ตัวเลข "มาตรฐาน" |
| คำว่า ประมาณการ | `costSource = estimated` |
| คำว่า ต้นทุนจริง | `costSource = saved` |
| บรรทัด มาตรฐาน ฿… | มี `standardTotalCost` |
| ข้อความยังไม่มีเวลามาตรฐาน | งานติดตามต้นทุน ยังไม่ยกเลิก ยังไม่ใช่ต้นทุนจริง และไม่มีเวลามาตรฐาน |
| ข้อความวัตถุดิบยังไม่มีราคา | มีการตวงแล้ว แต่ RM ว่างหรือไม่เกิน 0 และยังไม่ยกเลิก |
| ตัวกรองต้องตรวจสอบเวลา | `timerStatus = warn` มีขั้นตอนที่บันทึกเวลาไม่ครบ |
| ตัวกรองข้อมูลไม่ครบ | `costReliabilityPercent` น้อยกว่า 100 |
| ตัวกรอง Yield ต่ำ | มี RM มากกว่า 0 และ Yield น้อยกว่า 75 |
| ไม่โชว์ % Yield | RM ว่างหรือไม่เกิน 0 |
| เครื่องหมาย — | ค่าของช่องนั้นว่าง |

`timerStatus = warn` เมื่อมีขั้นตอนใน `process_executions` หรือ log แล้วอย่างน้อยหนึ่งขั้นตอนยังไม่จบ ถ้ามีเวลาผลิตแต่ไม่มีรายการขั้นตอน ระบบก็ถือว่าต้องตรวจสอบ

## สิ่งที่หน้าตัวอย่างทำไม่ได้

ไม่ดึงแผนผลิตของวันนี้ ไม่ค้นหาย้อนหลัง และไม่มีแท็บความครบของข้อมูลของหน้าหลัก การแก้สีหรือโครงบนไฟล์นี้ไม่กระทบระบบผลิต
